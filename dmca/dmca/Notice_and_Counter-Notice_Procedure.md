# Procédure DMCA : signalement de retrait et contre-signalement

1. **Réception d’un signalement**  
   - Noter la date et l’heure.  
   - Vérifier la présence des mentions obligatoires (coordonnées, URLs, déclarations).  
   - Archiver le signalement.

2. **Validation interne**  
   - Examiner si le contenu enfreint réellement un droit d’auteur.  
   - Consulter l’équipe juridique si nécessaire.

3. **Actions**  
   - **Si le signalement est jugé valide** :  
     - Retirer ou rendre privé le contenu sous 24 h.  
     - Accuser réception auprès du demandeur.  
   - **Si le signalement est douteux ou incomplet** :  
     - Demander des précisions.  
     - Suspendre la décision jusqu’à réception des compléments.

4. **Contre-signalement**  
   - Si vous estimez la demande abusive :  
     1. Rédiger un contre-signalement (incluant vos coordonnées, la référence du signalement, et une déclaration sous serment).  
     2. Envoyer ce contre-signalement à GitHub pour demander le rétablissement du contenu.  
     3. GitHub rétablit généralement le contenu sous 10–14 jours si aucune action judiciaire n’est engagée.

5. **Suivi et archivage**  
   - Conserver tous les échanges pendant 3 ans.  
   - Mettre à jour votre registre interne (dates, dépôts concernés, statuts des demandes).
