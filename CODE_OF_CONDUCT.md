# Code de Conduite

Nous voulons un espace de collaboration respectueux et inclusif.

## 1. Comportement attendu
- Respect mutuel.
- Communication constructive.
- Tolérance zéro pour le harcèlement.

## 2. Exemples de comportements proscrits
- Insultes, propos discriminatoires.
- Menaces ou harcèlement.
- Partage de données personnelles sans consentement.

## 3. Processus de signalement
Signalez tout problème via une issue privée sur GitHub ou à `contact@debunkcafe.fr`.

## 4. Sanctions
Selon la gravité, un contributeur peut recevoir un avertissement, être suspendu ou banni.
