# Guide de Contribution

Merci de votre intérêt pour Le Débunk Café!

## 1. Workflow GitHub
1. Forkez le dépôt.
2. Créez une branche `feature/mon-ajout`.
3. Faites vos modifications.
4. Ouvrez une Pull Request décrivant clairement vos changements.

## 2. Revue de code
- Respect des normes Markdown.
- Clarté des sources et références.

## 3. Tests
Vérifiez que les liens fonctionnent et que le contenu est lisible.

## 4. CLA
Avant toute PR, veuillez signer le [Contributor License Agreement](CONTRIBUTOR_LICENSE_AGREEMENT.md).
